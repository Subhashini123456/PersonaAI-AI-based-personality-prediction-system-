# 🧠 MindMetric AI

### AI-Based Personality Intelligence Dashboard

MindMetric AI is a professional web-based personality assessment project that analyzes a user's responses to 15 questions and generates a personalized personality profile.

The application presents the results through an interactive dashboard with personality scores, a radar chart, dominant trait analysis, and personalized insights.

---

## ✨ Features

- 🧠 15-question personality assessment
- 📊 Five personality dimension scores
- 📈 Interactive radar chart
- 🎯 Dominant personality trait detection
- 💡 Personalized personality insights
- 🎨 Professional and responsive dashboard
- 🔄 Retake assessment functionality
- 🌐 Flask-based web application

---

## 🧩 Personality Dimensions

MindMetric AI analyzes five major personality dimensions:

| Trait | Description |
|---|---|
| 💡 **Openness** | Creativity, curiosity, imagination, and openness to new experiences |
| 🎯 **Conscientiousness** | Organization, responsibility, discipline, and goal orientation |
| ⚡ **Extraversion** | Sociability, energy, communication, and enthusiasm |
| 🤝 **Agreeableness** | Empathy, cooperation, kindness, and consideration |
| 🌊 **Neuroticism** | Emotional sensitivity and response to stressful situations |
