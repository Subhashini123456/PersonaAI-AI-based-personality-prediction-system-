# Personality Predictor

A simple and interactive Flask web app that predicts your personality type based on your answers to 10 questions.

## Features

- Ask 10 personality questions.
- Predicts one of four personality types: **Introvert, Extrovert, Thinker, Creative**.
- Displays a short description for each personality type.
- Modern, responsive UI with styled HTML.
